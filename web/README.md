# EchoTrace Web Demo

在项目根目录启动：

```powershell
node web/server.cjs
```

打开 `http://127.0.0.1:8124`。

页面默认加载 `results/demo/` 中已经跑通的 `clip01` 端到端结果，也支持选择本地 WAV 后调用现有 `scripts/run_demo.py`，把实际 ASR 和纪要结果返回到页面。

仓库不提交录音文件。没有准备 `data/public/alimeeting/clips/clip01.wav` 时，默认页面仍可展示转写和纪要，但不会显示可播放的演示音频；选择本地 WAV 并开始分析后即可播放对应证据。

页面结构：

- 会议分析：唯一工作区入口，集中显示指标、原始转写、结构化纪要和证据回溯；
- 原始转写和结构化纪要：作为会议分析内部的内容区块，不单独占用导航入口；
- ASR/纪要评测结果保留在实验记录和小组展示材料中，不放进现场演示工作台。
